# v1.0.1

本版本将 `v1.0.1-rc.1` 的调度修复正式发布，并统一 Python 包与模块版本为 `1.0.1`。

## 修复与改进

- 修复多个工作流在同一计划时间到期时因比较 `WorkflowConfig` 导致的调度器崩溃。同时间任务按配置顺序串行执行，不同时间仍按计划时间排序。
- 增加同时间多工作流回归测试，保持严格未来调度、重启不补跑和单轮一小时预算。
- Compose 支持 `CHECKGRAM_IMAGE_TAG` 指定固定版本，默认仍为 `local`；README 补齐容器启动、环境变量、升级与回滚说明。
- 同步 `pyproject.toml`、`uv.lock` 和 `checkgram.__version__` 的版本值，修正模块版本长期停留在 `0.1.0` 的问题。

## 验证与兼容性

`v1.0.1-rc.1` 已完成 Release→GHCR 实测，原始 tag 与 SHA 标签可拉取，且未覆盖 `latest`。HostVDS 上相同业务代码的两个同时间工作流已在 2026-10-12 07:00（Asia/Shanghai）依次成功执行。

正式发布工作流会重新执行 Ruff、格式检查、mypy、pytest、AMD64 镜像构建与 Compose 校验，再推送 `v1.0.1`、`sha-<完整提交 SHA>` 和 `latest` 标签。

本版本不改变工作流配置、认证会话、重试预算或持久数据格式，无需数据迁移。生产部署应固定 `v1.0.1`；升级前备份配置、环境文件与会话卷，保留原镜像和 Compose 文件。部署与最终验收证据见 [MVP 验收记录](../mvp-acceptance.md)。
